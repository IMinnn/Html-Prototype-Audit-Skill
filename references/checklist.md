# B 端 HTML 原型检查参考

将本参考转为当前原型的检查矩阵；适用项必须实际操作，不适用项写明原因。下列规则检查前端表现，不要求真实服务。不要把建议项机械地当成必需功能。

## A. 入口、导航与页面关系

- 菜单可展开/收起，选中项和实际页面一致；相同名称与图标表达一致含义。
- 所有声明的入口、面包屑、详情链接、返回按钮和页签可达；页面标题与入口相符。
- 弹窗、抽屉、二级详情有明确退出路径，关闭后回到合理位置；无意跳首页或丢失关键筛选需记录。
- 新窗口打开、锚点、浏览器前进/后退和刷新按声明的路由方式工作；单页原型不强制要求每一页独立 URL，但已有路由不应错乱。
- 控件显示与权限/状态相符；禁用有可理解原因，隐藏动作不造成无法完成任务。
- 首页/看板卡片若表现为可点击，应有对应去向；纯展示卡片不强制可点。

## B. 功能完整性与业务闭环

- 按对象性质判断 CRUD 是否适用；只读、留痕、不可逆状态对象尊重需求约束。
- 新增：有入口、有效字段、校验、保存、取消、成功反馈、结果去向；同名记录如何处理按需求判断。
- 查看：选中记录与详情对应，关联数据、附件及状态准确；无数据不是永远展示同一条详情。
- 编辑：正确回填、可修改范围明确、取消不误保存、保存后列表与详情联动；未修改直接保存不应制造矛盾反馈。
- 删除：对象和影响范围清楚，必要时确认，可取消；删除后选中项、总数、详情、空态与分页同步。
- 批量操作：单选/全选/跨页范围明确，选中数量正确；不合条件记录的处理有解释，不默默越权或作用于错误对象。
- 多步流程：上一步保留合理输入，下一步校验当前内容，最终动作与中间步骤有区分。
- 状态流转：发起、暂存、提交、撤回、驳回、重提、终止、完成等仅检查适用操作；状态、可用动作、记录与时间线相符。避免“已完成”仍可重复提交或详情与列表状态矛盾。
- 跨模块：创建/变更后关联选择、统计卡片、详情、记录等按原型声明联动，名称/标识/枚举一致。模拟范围之外的联动明确列为不适用或待确认。
- 无出口、死循环、下一步永远禁用、关键按钮只显示占位提示，按其阻断程度报问题。

## C. 表单、反馈与恢复

- 必填、字段说明、格式、长度、边界值、日期先后、数值范围和单位明确；只检查已知业务规则与通用格式。
- 标签与输入框对应，错误定位到字段，有可理解文案；修改后错误可消除；前后空格、空输入、中文和常见特殊字符合理处理。
- 关联下拉切换父项后，子项不保留无效值；单选、多选、日期范围和清空行为一致。
- 保存与取消、确认与关闭含义稳定；未保存离开会造成明显损失时，检查是否保留或提醒。
- 不要求人为增加延迟；若有加载/提交过程，应防止重复点击产生重复记录，并能结束加载。
- 空数据、搜索无结果、加载、错误、禁用、成功等适用状态有解释和下一步动作；演示工具可模拟时验证，否则写未验证。
- 重置恢复定义的默认值，不误删除记录；失败后能重试或返回；提示不永久遮挡控件。

## D. 列表、搜索、筛选、排序与分页

- 列标题、字段值、单位、时间、空值和操作列对齐；长文本有可识别的截断或完整查看方式。
- 搜索明确作用字段和触发方式；检查已存在值、不存在值、空值、清空以及回车/按钮的一致性（如两者存在）。
- 多条件筛选组合按声明的逻辑执行；查询、清空、重置、条件标签和结果数量对应，日期边界符合规则。
- 有排序入口时检查升序、降序及默认恢复（如支持），数字与日期不能按文本顺序错排；声明全结果排序时不能只排序当前页。
- 不是所有列都必须支持排序；缺少排序/搜索入口需结合任务和数据规模判断，必要时列体验建议。
- 可增长的管理列表应检查分页或合理替代方案。固定少量展示、树形结构、明确的无限加载等，可说明替代机制，不机械要求分页。
- 分页不只看控件：切换后记录变化，检查首末页、上一页/下一页禁用、总数、页码、页容量；有跳页时检查越界输入。
- 搜索/筛选/改页容量/删除最后一条后，页码归位或纠正，避免“有记录却空白”；总数是筛选后总量，当前页条数正确。
- 排序、查询、翻页、返回详情后的条件保留策略自洽；不能同时展示“第 2 页”和第 1 页的数据。
- 全选是当前页还是全部结果需可理解；过滤或翻页后的选中范围不能悄悄作用到错误记录。
- 少于一页数据不能证明翻页通过；无法安全补充样例时标记该场景未验证，并说明需要的数据量。

## E. 文件上传、预览、下载与导入导出

- 上传：选择、取消选择、多选/单选、再次选择同名文件、删除/替换；声明的类型、数量、大小限制与提示一致。
- 上传后展示文件名、状态和必要信息；取消表单/移除附件后状态正确；可用浏览器本地 File/Blob 模拟，不要求云端保存。
- 预览：内容对应所选文件；图片缩放、文档查看、翻页等仅按声明能力检查；不支持格式要有说明或下载路径。
- 下载：实际触发可取得的文件，核对名称、扩展名、是否为空、内容与所选对象是否一致；不能仅凭“下载成功”提示判定通过。
- 若自动化环境无法取得下载文件，记录已触发及未核验的部分，不能声称内容正确。
- 模板下载与导入字段一致；存在导入功能时检查合法样例、缺字段/错误格式、成功和失败数量、错误定位、重复数据处理（规则未知列待确认）。
- 导出：明确导出选中记录、筛选结果还是全部；文件内容应符合范围，不能永远导出固定无关样例。
- 原型允许示例附件，但名称、内容、说明和演示范围应自洽；网络/系统权限拦截单独记环境限制。
- 使用最小无敏感内容样例，不使用真实客户附件，不对外上传或发送测试文件。

## F. 视觉、布局与风格一致性

- 优先按产品已有设计规范检查。简约指层级清楚、装饰克制、信息易扫读、主要操作突出；不等于删除必要字段或把所有页面做成同一种布局。
- 对比各页面的色彩、字体层级、间距、圆角、边框、阴影、图标、按钮尺寸与主次、表格密度、弹窗和抽屉结构；区分有意差异与无规则漂移。
- 标题、面包屑、查询区、工具栏、表格、分页的结构稳定；同义操作名称和位置稳定。
- 文字不裁切重叠，按钮不被遮挡；对比度足以辨认正文、次要文案、禁用态与状态标签，状态不只靠颜色区分。
- 展开筛选、长标题、长文件名、较多标签和大量表格行时仍可操作；横向滚动、固定列、固定表头、分页和底部按钮不互相覆盖。
- 弹窗高度与滚动区合理，标题、关闭、主操作可达；遮罩层级正确，不穿透点击或出现背景滚动失控。
- 较小桌面和浏览器缩放时检查主要任务是否仍可完成；非支持设备的问题单列，不扩大验收边界。
- 视觉缺陷应附实际截图位置和尺寸；审美建议写出具体改变与收益，避免“太丑”“不高级”等不可执行结论。

## G. 操作便捷性与基础可访问性

- 高频任务路径不过度绕行，批量场景有适用方式；危险操作不与常用主操作混淆。
- 鼠标悬停、焦点、选中、禁用状态可区分；图标按钮能识别含义，必要时有提示。
- Tab 顺序基本合理，焦点可见；输入、选择、提交能按控件语义用键盘完成。支持 Escape 关闭时应遵守未保存处理，关闭后焦点回到合理入口。
- 弹窗打开后背景交互不抢焦点，内容不会把用户困在无法离开的状态；关键反馈可被理解和再次找到。
- 时间、数量、状态、责任人及失败原因等帮助决策的信息清晰，避免只出现技术错误码。
- 不以完整 WCAG 认证或生产安全合规作为本技能默认交付。

## H. 运行与需求对照

- 页面无白屏、关键资源失效、主要按钮脚本报错；可读取控制台时关联真实操作记录，不能仅凭无报错认定通过。
- 记录受网络、跨域、文件权限、外部资源影响的阻塞；区分环境限制与原型自身缺陷。
- 需求逐项映射到入口、页面、状态与场景；只有需求明确要求且证据充分，才报告缺失功能。
- 有需求无入口、有入口无功能、有功能无完成反馈、有流程无终点，分别定位，不合并成笼统“功能不完善”。
- 字段、术语、角色、状态、时间线与需求一致；冲突引用具体材料位置并待确认，不擅自选择一个版本。

## I. 用户可见文案不得暴露演示或实现性质

- 作为明确检查要求执行：产品界面不应出现“当前是演示 Demo”“仅前端演示”“暂时不接数据”等说明，也不应出现同义表达，如“原型展示”“模拟数据”“假数据”“静态演示”“未接入后台”“尚未对接接口”“仅展示效果”“实际功能待开发”“点击仅模拟操作”等。按表达含义判断，不局限于这些原句。
- 检查范围包括登录页、首页、各业务页面、标题与浏览器页签、横幅、角标、页脚、帮助说明、占位文字、空态、弹窗、抽屉、悬浮提示，以及点击、提交、上传、下载后出现的 Toast、alert、成功/错误反馈。可由辅助技术读取的控件说明也应采用正常业务文案。
- 先实际浏览并触发交互，再在任务范围内辅助搜索 `demo`（忽略大小写）、演示、原型、模拟、假数据、前端、静态、后台、接口、待开发、未接入、未对接等线索；检查脚本动态拼接、文案资源及 CSS 生成内容。关键词只是候选，需结合上下文确认；仅存在于代码注释、变量名、不可见调试日志或独立检查报告中的技术说明，不算界面文案问题。
- 不误删正常业务含义，如业务中的“应急演练”“模拟考试”“数据接口管理”，以及合法业务记录、文件名或产品名称中恰好含有 Demo 的内容。检查对象是解释当前产品处于演示/未实现状态的文字，不是一律禁用这些字符。
- 发现后记录页面、模块、原文、出现位置和触发步骤，归入确认问题，而非仅列审美建议。共享文案可合并，但应列明所有已发现的页面和触发入口。
- 修改建议应具体：纯解释性横幅、角标或说明可删除并收拢留白；操作提示改为与实际前端结果相符的业务反馈。若按钮确实无有效操作，另外记录功能缺陷，不能仅把“仅演示”替换成“操作成功”来掩盖未闭环。
- 验收：实际重走原触发路径，页面与动态提示均无此类说明；保留必要业务解释和真实状态，不凭空宣称“已同步服务器”“已发送邮件”等未发生的结果；删除文案后布局无多余留白、遮挡或错位。无法触发的候选文案列为待核验线索，不能宣称全量清除。
